FunctionSwitchboard

One RemoteFunction that routes calls from clients to a server callback chosen by port name, created with Sencha.funcSwitchboard. Every port shares the same argument types.

Each port has its own rate limit budget per player, so unrelated actions don't share one. Calls to a port with no callback are rejected. 

-- server
shopSwitchboard:connect("buy", function(player, itemId)
	return true
end)

-- client
local bought = shopSwitchboard:invokeServer("buy", 12)

Calls the server callback for port and returns what it returns, showing predictions on their replicators until the server has handled this call. Build each prediction with a replicator's prediction method.

The server must make this call's replicator changes before its handler returns. See Client prediction.

This item only works when running on the server. Server

FunctionSwitchboard:rateLimit(limit: Limit) → FunctionSwitchboard

Sets the rate limit for calls to each port from each player, replacing the default of 60 at once and 30 per second. Returns the same switchboard, so it can be chained where it's created. Errors if the limit is invalid.
