Sencha

Typed remotes and server-owned state for Roblox. Define remotes and replicators together in one shared module with Sencha.define, and require it on the server and the client. 

-- ReplicatedStorage/CurrencyNetwork.luau
local Sencha = require(ReplicatedStorage.Packages.Sencha)
local gt = require(ReplicatedStorage.Packages.GreenTea)

return Sencha.define(script, {
	buyItemRemote = Sencha.func(gt.args(gt.string()), gt.returns(gt.boolean())),
	coinsReplicator = Sencha.temporaryReplicator.player(gt.number(), 0),
})

Types​

Disconnect​

</>
type Disconnect = () → ()

Every listener method returns a Disconnect, the cleanup function. Call it to stop listening. It's safe to call more than once, and can be handed to a cleanup library or returned from a React effect.

Prediction​

</>
type Prediction = {
channel: any,
predict: any
}

A prediction for one replicator, built with that replicator's prediction method and passed to a predicted remote call such as invokeServerPredicted or fireServerPredicted.

channel is typed any to work around a limitation in Luau's older type checker. Predictions are still type-checked when you create them. Each replicator's prediction method checks its function or patch against that replicator's value type.

Limit​

A rate limit for calls from clients, passed to :rateLimit(...) on any remote. Each player has their own budget.

Properties​

temporaryReplicator​

</>
Sencha.temporaryReplicator: {
player: (
valueType,
defaultValue,
incrementalConfig?
) → TemporaryPlayerReplicator,
global: (
valueType,
initialValue,
incrementalConfig?
) → TemporaryGlobalReplicator
}

Creates replicators for state the server keeps in memory.

  • temporaryReplicator.player creates a [TemporaryPlayerReplicator]: one value per player, sent only to that player.
  • temporaryReplicator.global creates a [TemporaryGlobalReplicator]: one value, sent to every player.
carriedOreReplicator = Sencha.temporaryReplicator.player(gt.number(), 0),
meteorShowerReplicator = Sencha.temporaryReplicator.global(gt.boolean(), false),

unreliableEvent​

</>
Sencha.unreliableEvent(
...: GreenTeaType--

the type of each argument

) → Event<T...>

Creates an Event backed by an UnreliableRemoteEvent. It has the same API as Sencha.event, but messages may be dropped or arrive out of order, and payloads are limited to roughly 900 bytes. Use it for repeating updates where only the latest matters, never for messages that must arrive.

define​

</>
Sencha.define(
parent: Instance,--

usually script

implementations: T--

a table of remotes and replicators

) → T

Names and sets up every remote and replicator in implementations from its key, and returns the same table. Remotes are created under parent, and each replicator's name is parent:GetFullName() plus its key, so the same module resolves to the same remotes and replicators on both sides.

Each remote and replicator can only be defined once.

waitForReplicators​

This item only works when running on the client. ClientThis is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
Sencha.waitForReplicators() → ()

Yields until every replicator the server has defined has its first value on this client, including ones whose modules the client hasn't required yet. After this returns, get() is safe on every replicator.

Call this once while loading, before starting systems that read replicated values. If this is still waiting after 5 seconds, a warning lists the replicators that don't have a value yet.
