TemporaryGlobalReplicator

One value the server keeps in memory and sends to every player, created with Sencha.temporaryReplicator.global. Per-player data never goes through a global replicator unless you put it there, so the server always chooses what becomes public.

Functions​

get​

</>
TemporaryGlobalReplicator:get() → T

Returns the current value without yielding.

On the client, errors if the value hasn't arrived yet. Call Sencha.waitForReplicators while loading, or use TemporaryGlobalReplicator:getAsync or TemporaryGlobalReplicator:observe in code that may run earlier.

getAsync​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
TemporaryGlobalReplicator:getAsync() → T

Returns the current value, yielding until it's available. The server value always exists, so this only yields on the client.

set​

This item only works when running on the server. Server
</>
TemporaryGlobalReplicator:set(value: T) → ()

Sets the value and sends it to every player. Errors if the value doesn't match the replicator's type. Setting a primitive to the value it already has does nothing; setting a table always counts as a change.

tryUpdate​

This item only works when running on the server. Server
</>
TemporaryGlobalReplicator:tryUpdate(callback: (value: T) → (
boolean,
T?
)) → boolean

Calls callback with the current value. If it returns true and a new value, the value is set as with TemporaryGlobalReplicator:set; if it returns false, nothing changes. Returns what callback returned first.

callback must not yield, so nothing else can change the value between reading and setting it.

local didStart = EventsNetwork.meteorShowerReplicator:tryUpdate(function(isActive)
	if isActive then
		return false
	end
	return true, true
end)

applyIncrementalUpdate​

This item only works when running on the server. Server
</>
TemporaryGlobalReplicator:applyIncrementalUpdate(patch: P) → ()

Applies patch to the value with the incremental config's apply, then sends only the patch to every player. Errors if the patch or the new value doesn't match its type, or if the replicator has no incremental config. An empty table patch does nothing.

onChanged​

</>
TemporaryGlobalReplicator:onChanged(callback: (
newValue: T,
oldValue: T
) → ()) → Disconnect

Calls callback when the value changes, not for the initial value.

On the server, the change is sent to clients before callback runs, so anything it changes in response reaches clients after the change that caused it.

observe​

This item only works when running on the client. Client
</>
TemporaryGlobalReplicator:observe(callback: (
newValue: T,
oldValue: T?
) → ()) → Disconnect

Calls callback with the current value right away if it has arrived (otherwise when it arrives), then on every change. oldValue is the value before the change, or nil for the first call. 

EventsNetwork.meteorShowerReplicator:observe(function(isActive, wasActive)
	if isActive and wasActive ~= true then
		print("a meteor shower started")
	end
end)

onUpdateReceived​

This item only works when running on the client. Client
</>
TemporaryGlobalReplicator:onUpdateReceived(callback: (
newValue: T,
oldValue: T,
patch: P
) → ()) → Disconnect

Calls callback for each patch received, after the value is updated. Only replicators with an incremental config receive patches; calling this on one without errors.

Whole values (the first value, or a set) don't fire this; use TemporaryGlobalReplicator:onChanged to see every change.

getObservable​

This item only works when running on the client. Client
</>
TemporaryGlobalReplicator:getObservable() → ObservableValue<T>

Returns an ObservableValue that follows the replicated value, for code that works with ObservableValues, like the ReactObservableValue hooks. Calling this again returns the same one. Setting it doesn't change the replicated value. Errors if the value hasn't arrived yet. 

local isMeteorShower = ReactObservableValue.useObservableValue(EventsNetwork.meteorShowerReplicator:getObservable())

isLoaded​

This item only works when running on the client. Client
</>
TemporaryGlobalReplicator:isLoaded() → boolean

Returns whether the value has arrived from the server.
