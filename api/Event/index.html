Event

A typed RemoteEvent, created with Sencha.event or Sencha.unreliableEvent. Arguments are checked against its GreenTea types: calls from your own code error on bad types, and calls from clients with bad types are rejected on the server.

Calls from clients are also rate limited. Rejected calls are dropped, and the server warns once per player, remote and reason, then stays quiet for that combination for 60 seconds.

Calls callback whenever a client fires this event, after the call passes the rate limit and type check. Each call spends one token and is checked once, however many listeners there are.

rateLimit​

This item only works when running on the server. Server
</>
Event:rateLimit(limit: Limit) → Event

Sets the rate limit for calls from each player, replacing the default of 60 at once and 30 per second. Returns the same event, so it can be chained where it's created. Errors if the limit is invalid. 

exportItemRemote = Sencha.event(gt.string()):rateLimit({ burst = 10, perSecond = 4 }),
